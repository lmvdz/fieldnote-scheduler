PROTOTYPE / SINGLE-OWNER WORKSPACE

Know what is connected.

The simulator creates no real appointment. Fixed UTC windows and fixture pricing are for demonstration; calendar sync is outside this prototype.

The workspace reports whether it is using a simulator, configured AI, or PayPal sandbox. A local test result is not a live-provider result.

For judge access, the repository includes setup instructions. Hosted access is supplied privately by the entry owner.

03 / BEFORE YOU BEGIN
Does this move real money?

No. The default is a labeled simulator. The optional PayPal adapter targets the sandbox only, using test funds and an explicit approval flow.

What does the AI control?

AI can extract service scope and quantities from allowlisted fictional requests. Catalog prices, quote totals, approval, slot locking, and payment checks stay deterministic. Ambiguity must be resolved before approval, and unavailable AI falls back to labeled rules.

How can I inspect or run it?

The MIT-licensed source and setup instructions are available on GitHub. Run the fixture workflow locally, or request private hosted access from the entry owner.

Is this ready for business use?

This is a hackathon prototype with synthetic data. Provider interoperability, operating policies, and business deployment need separate validation.
